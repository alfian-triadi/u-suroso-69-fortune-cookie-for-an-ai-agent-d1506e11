One funny fortune cookie line for an AI agent, written in the voice of a fortune slip: an agent's context window fills up mid-sentence, and its final words are cut off mid-thought. Built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the single fortune line to `/output/entry.txt` (UTF-8, one line, no trailing newline).
